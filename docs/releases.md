# Publishing releases

The source can be installed now with `cargo install --path . --locked`. Releases target [ericseppanen999/spotify-cli](https://github.com/ericseppanen999/spotify-cli). The checked-in `.github/workflows/release.yml` is generated by cargo-dist 0.31.0.

To publish a release:

1. Install the pinned release tool: `cargo install cargo-dist --version 0.31.0 --locked`.
2. Run `dist generate --check` and `dist plan` to verify the workflow and release artifacts.
3. Update the version in Cargo.toml and regenerate Cargo.lock as needed. Commit the changes.
4. After CI passes, push a version tag matching Cargo.toml, for example `v0.1.0`.

The generated workflow builds Windows, Linux, and Intel/Apple Silicon macOS binaries, generates shell/PowerShell installers, and uploads assets to a GitHub release. Use the installer URLs in the generated release notes for the one-line install instructions in README.md after the first release exists. No release has been published by the implementation process.

Publishing to crates.io is optional and separate; check the package name is available before publishing.
